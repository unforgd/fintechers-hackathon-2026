# Unforgd — who pays when the cold chain breaks?

**The FinTechers `$ hackathon_` 2026, Prague · Track 7 · Open / wildcard · Team Unforgd**
Maxim Lomovskoy, Wanderson Carvalho, Aissa Iglikova (42 Prague)

An insurer pays EUR 250,000 for a spoiled vaccine shipment. To recover the money it must prove which party broke
the cold chain, while the carrier submits a "clean" temperature log. Unforgd checks the custody chain that was
**fingerprinted at every handover**, finds the document that was **altered after registration**, locates the
**first broken step**, computes the **recoverable amount and the payment decision in code**, and has **Claude Opus 4.5
on Amazon Bedrock** explain the finding and draft a **cited recovery letter**, checked against the code's result.

**Decision support for a human adjuster, not a verdict.** All data is synthetic.

## Run it

Python 3.10+. No dependencies for the offline run.

```bash
python3 demo.py                       # rules + cached AI answer + HTML report (opens in the browser)
pip install boto3                     # for the live AI step
aws sso login --profile hackathon     # team AWS account, eu-central-1
python3 demo.py --live --profile hackathon
```

Output: `results/VAX-001.html` (the demo screen), `results/VAX-001.assessment.json`, `results/VAX-001.llm.json`.

## How it works

| Step | Where | What |
|---|---|---|
| 1. Custody chain | `unforgd/claims.py` | At each handover (manufacturer → carrier → distributor) the documents and the raw data-logger readings are fingerprinted (SHA-256) and the events are hash-chained |
| 2. Verify | `unforgd/rules.py` | Recompute every event hash and link; compare each submitted document with its registered fingerprint |
| 3. Decide in code | `unforgd/rules.py` | Excursions outside 2–8 °C in the registered readings → first broken step → liable party → clauses → recoverable amount (deductible, liability cap) → freight invoice withheld or released |
| 4. Explain with AI | `unforgd/explain.py` | Claude Opus 4.5 (Bedrock, `eu-central-1`, Sonnet 4.5 fallback) returns JSON: summary, clauses, evidence IDs, recovery letter. **Validated**: party, clauses and amount must equal the code's result; only known evidence IDs may be cited |
| 5. Report | `unforgd/report.py` | One page for the adjuster, incl. the measured result |
| 6. Measure | `unforgd/rules.py` | 10 synthetic claims with known ground truth (carrier, distributor, manufacturer, no excursion; with and without altered logs) |

**Why not a GPT wrapper:** a language model summarises a forged PDF politely. Here the fingerprints and rules
establish *that* a record was altered and *who* broke the chain; the model only explains *what* happened and
drafts the letter, and its answer is rejected if it contradicts the code.

**Limits:** fingerprints prove a record was not changed after registration and who registered it, not that it was
true at registration. Measured 10/10 is on synthetic claims generated by the same team: a smoke test, not accuracy
on real claims.
